## SoundVolumeView

`tools/SoundVolumeView/` contains NirSoft's **SoundVolumeView**, included
unmodified as freeware. It is used only as a fallback when Windows blocks the
default-audio-device API. Distribution follows the terms in
`tools/SoundVolumeView/readme.txt`; it is not sold and not part of a commercial
product.

## VB-CABLE

**VB-CABLE** by VB-Audio is an external dependency. It is not included in this
repository or the release zip. Users install it separately from
<https://vb-audio.com/Cable/>.

## Python packages and FFmpeg

Built releases bundle Python, PySide6, NumPy, sounddevice, soundfile, imageio,
imageio-ffmpeg, Mutagen, soundcard, and FFmpeg. Each keeps its own license.
